# Text Editor | Custom Data Structures & Memory Management

**C++ | Data Structures | Memory Management | Object-Oriented Programming**

## Overview
Developed a terminal-based text editor in C++ using a custom doubly linked list to manage and manipulate text. The project supports interactive editing, cursor navigation, and position tracking while emphasizing efficient data structure design and manual memory management.

The project explores how low-level data structures and iterators can support higher-level applications such as text editors.

## Key Features
- **Custom Doubly Linked List:** Implements a linked list data structure with bidirectional traversal and iterator support.
- **Interactive Text Editing:** Supports inserting and deleting characters through a terminal-based interface.
- **Cursor Navigation:** Allows movement left, right, up, and down, as well as navigation to the beginning and end of lines.
- **Position Tracking:** Maintains cursor row, column, and character index during editing operations.
- **Memory Management:** Uses dynamic allocation and deallocation to manage linked list nodes.

## Technical Highlights
- Implemented a templated doubly linked list in C++ without relying on STL containers for the underlying list.
- Developed custom iterators to support traversal and modification of text data.
- Applied pointer manipulation and dynamic memory management to support insertion and deletion operations.
- Designed a text buffer abstraction that tracks cursor position and coordinates.
- Used unit testing to validate linked list and text buffer behavior.

## Skills Demonstrated
C++, data structures, doubly linked lists, iterators, pointers, dynamic memory management, templates, object-oriented programming, unit testing, and debugging.
